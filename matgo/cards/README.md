# 화투 카드 그림 출처

`00.svg` ~ `47.svg` 는 위키미디어 공용의 "SVG Hwatu" 세트(제작자: Spenĉjo, 2024)를 그대로 가져온 것입니다.
라이선스: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)

- 세트: https://commons.wikimedia.org/wiki/Category:SVG_Hwatu
- 예: https://commons.wikimedia.org/wiki/File:Hwatu_January_Hikari.svg

파일 번호 = (달 − 1) × 4 + 순서. 순서는 `engine.js` 의 SPEC 과 같습니다 (예: 1월 → 광, 홍단, 피, 피 / 11월 → 광, 쌍피, 피, 피 / 12월 → 비광, 제비, 비띠, 쌍피).
