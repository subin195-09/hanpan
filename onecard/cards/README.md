# 트럼프 카드 그림 출처

`00.svg` ~ `53.svg` 는 Byron Knoll 이 그린 트럼프 세트로, 작가가 퍼블릭 도메인(PD-author)으로 공개했습니다. 출처 표기는 필수가 아니지만 남겨 둡니다.

- 세트: https://commons.wikimedia.org/wiki/Category:Playing_cards_set_by_Byron_Knoll
- 파일 번호 = 무늬(0 ♠, 1 ♥, 2 ♦, 3 ♣) × 13 + 순위(0 = A … 12 = K). 52 = 컬러(빨간) 조커, 53 = 흑 조커.
- 인물 카드(J·Q·K)와 스페이드 A 는 세트의 새 그림("…2.svg") 판을 썼고, 인물 카드는 헤드리스 크롬으로 334×485 PNG 로 구웠습니다(원본 SVG 가 장당 1MB 안팎이라).
- 조커 두 장(`52.png` 컬러 = 빨강, `53.png` 흑 = 검정)은 David Bellot 의 SVG-cards 세트(LGPL 2.1, https://commons.wikimedia.org/wiki/File:English_border_red_joker.svg , https://commons.wikimedia.org/wiki/File:English_border_black_joker.svg)를 334×485 PNG 로 구운 것입니다. LGPL 저작물이므로 출처와 라이선스 표기를 유지합니다.
- 뒷면 `back.png` 는 Trocche100 의 "Card back red.svg"(CC0, https://commons.wikimedia.org/wiki/File:Card_back_red.svg)를 334×485 PNG 로 구운 것입니다.
